| `index.html` / `style.css` | 页面、对话框、自适应样式 |

| `src/engine.js` | 细胞演化、边界与几何遍历 |

| `src/font-worker.js` | 后台生成 OpenType 矢量字体 |
| `scripts/` | 零依赖预览服务器和静态构建 |
| `tests/` | 演化、边界、SVG 和 OTF 验证 |
